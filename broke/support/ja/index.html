よくある質問

広告削除の購入を復元したいです。
アプリの設定 → 広告削除 → 購入を復元を押してください。購入したときと同じApple Accountでサインインしている必要があります。

インターネットがなくても遊べますか?
はい、ひとりで遊ぶオフラインのゲームです。インターネットがなくても遊べます。広告はつながっているときだけ表示されます。

アプリを削除したら記録が消えました。
ゲームの記録はスマホの中だけに保存されます。アプリを削除すると記録も一緒に消え、バックアップや別のスマホへの引き継ぎには対応していません。

言語を変えたいです。
アプリはスマホの言語に合わせて表示されます。韓国語、英語、日本語、中国語(簡体字・繁体字)に対応しています。iPhoneの設定 → アプリ → 金欠脱出 → 言語で、このアプリだけ言語を変えることもできます。

お金が円で表示されるのはなぜですか?
お金は言語に合わせた通貨に、決まったレートで換算して表示します。ゲームの舞台は韓国に似た世界なので、給料や家の値段などは韓国の水準になっています。

振動や事件の絵をオフにしたいです。
アプリの設定で振動と事件・ニュースの大きな絵をオフにできます。

広告のプライバシー設定はどこで変えられますか?
同意が必要な地域(EEA・英国など)では、アプリの設定 → 広告のプライバシー設定で変更できます。トラッキングの許可はiPhoneの設定 → プライバシーとセキュリティ → トラッキングで変更できます。
