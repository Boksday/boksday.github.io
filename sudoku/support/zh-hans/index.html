常见问题

下一个段位是锁着的。
在前一个段位赢一局即可解锁。每日一题不计入段位解锁。

出错 3 次会怎样？
本局会暂停。看完广告即可清除错误数字并获得一次机会继续这一局，也可以不看广告直接开始新游戏。

提示能用几次？
每局 1 次免费。之后看完一段短广告可再获得 1 次提示。购买移除广告后，使用提示无需看广告。

移除广告是订阅吗？
不是。这是一次购买、永久有效的商品，不会自动续费。

换手机或重新安装后又出现了广告。
请使用相同的 Apple ID 或 Google 账号登录，然后在应用中点按设置 → 移除广告 → 恢复购买。

记录不见了。
记录只保存在手机里。删除应用后记录也会一并删除，且不会转移到其他手机。

Game Center 排行榜上看不到我的成绩。
需要在设备的设置 → Game Center中登录。登录后完成的游戏才会计入排行榜和成就。

如何添加小组件？
iPhone：长按主屏幕空白处 → 编辑 → 添加小组件 → BySide:Sudoku
