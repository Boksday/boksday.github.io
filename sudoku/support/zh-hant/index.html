常見問題

下一個段位是鎖著的。
在前一個段位贏一局即可解鎖。每日一題不計入段位解鎖。

出錯 3 次會怎樣？
本局會暫停。看完廣告即可清除錯誤數字並獲得一次機會繼續這一局，也可以不看廣告直接開始新遊戲。

提示能用幾次？
每局 1 次免費。之後看完一段短廣告可再獲得 1 次提示。購買移除廣告後，使用提示無需看廣告。

移除廣告是訂閱嗎？
不是。這是一次購買、永久有效的商品，不會自動續訂。

換手機或重新安裝後又出現了廣告。
請使用相同的 Apple ID 或 Google 帳號登入，然後在 App 中點一下設定 → 移除廣告 → 恢復購買。

紀錄不見了。
紀錄只儲存在手機裡。刪除 App 後紀錄也會一併刪除，且不會轉移到其他手機。

Game Center 排行榜上看不到我的成績。
需要在裝置的設定 → Game Center中登入。登入後完成的遊戲才會計入排行榜和成就。

如何加入小工具？
iPhone：長按主畫面空白處 → 編輯 → 加入小工具 → BySide:Sudoku
