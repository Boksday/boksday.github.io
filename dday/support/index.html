자주 묻는 질문

Pro 구독은 어떻게 해지하나요?
아이폰: 설정 → Apple ID(내 이름) → 구독 → 내곁의 디데이 → 구독 취소
Android: Play 스토어 → 프로필 → 결제 및 정기 결제 → 정기 결제 → 내곁의 디데이 → 해지
앱 설정의 Pro 영역에 있는 구독 관리로도 바로 갈 수 있어요. 해지해도 이미 결제한 기간이 끝날 때까지 Pro를 쓸 수 있어요.

폰을 바꾸거나 앱을 다시 설치했더니 Pro가 꺼졌어요.
같은 Apple ID·Google 계정으로 로그인한 뒤 앱의 설정 → Pro → 구매 복원을 눌러 주세요.

쿠폰 코드는 어디에 넣나요?
앱의 설정 맨 아래 → 쿠폰 코드 사용을 누르면 스토어의 코드 입력 화면이 열려요. 입력한 뒤 앱으로 돌아오면 Pro가 켜져요.

폰을 바꾸면 디데이가 사라지나요?
디데이는 폰 안에만 저장돼요. 바꾸기 전에 설정 → 백업 파일 내보내기로 파일을 만들어 메일·클라우드 드라이브 등에 보관하고, 새 폰에서 백업 파일 불러오기를 하면 그대로 옮겨져요.

알림이 오지 않아요.
휴대폰 설정에서 '내곁의 디데이' 알림이 허용돼 있는지 확인해 주세요. 디데이마다 당일 알림·미리 알림이 켜져 있어야 해요. 알림 시각은 앱 설정에서 바꿀 수 있고, 휴대폰이 배터리를 아끼는 중이면 조금 늦게 올 수 있어요.

홈 화면 위젯은 어떻게 추가하나요? (Pro)
아이폰: 홈 화면 빈 곳을 길게 누르고 → 편집 → 위젯 추가 → '내곁의 디데이'
Android: 홈 화면 빈 곳을 길게 누르고 → 위젯 → '내곁의 디데이'

음력 생일은 어떻게 계산되나요?
한국천문연구원 기준 음력을 써요. 윤달 생일인데 그해에 그 윤달이 없으면 평달로, 30일인데 그달이 29일까지면 29일로 맞춰요.

FAQ

How do I cancel my Pro subscription?
iPhone: Settings → your name → Subscriptions → Naegyeot D-Day → Cancel Subscription
Android: Play Store → profile → Payments & subscriptions → Subscriptions → Naegyeot D-Day → Cancel
You can also tap Manage subscription in the Pro section of the app's settings. After canceling, Pro stays on until the end of the period you paid for.

Pro turned off after I changed phones or reinstalled the app.
Sign in with the same Apple ID or Google account, then tap Settings → Pro → Restore purchase in the app.

Where do I enter a coupon code?
Tap Redeem a code at the bottom of the app's settings. The store's code screen opens; after redeeming, return to the app and Pro turns on.

Will my D-Days disappear if I change phones?
D-Days are stored only on your phone. Before switching, use Settings → Export backup file and keep the file somewhere safe (email, cloud drive). On the new phone, use Import backup file.

I don't get reminders.
Check that notifications for Naegyeot D-Day are allowed in your phone settings and that reminders are turned on for each D-Day. You can change the reminder time in the app's settings. Reminders may arrive a little late while your phone saves battery.

How do I add a home screen widget? (Pro)
iPhone: long-press an empty spot on the home screen → Edit → Add Widget → Naegyeot D-Day
Android: long-press an empty spot on the home screen → Widgets → Naegyeot D-Day

How are lunar birthdays calculated?
We use the Korean lunar calendar (Korea Astronomy and Space Science Institute). If a leap-month date doesn't exist in a given year, we use the regular month; if day 30 doesn't exist, we use day 29.
