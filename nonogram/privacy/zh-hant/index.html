BySide 數織 隱私權政策

生效日期：2026年10月11日

BySide 數織（以下簡稱「本應用程式」，iOS 和 Android）重視你的隱私。本政策說明本應用程式處理哪些資訊以及如何處理。

1. 本應用程式蒐集的資訊

本應用程式沒有註冊或登入，也不會把你的資訊傳送到營運者的伺服器或資料庫。營運者不會從本應用程式收到任何資訊。

解開的圖畫、進行中的遊戲、獎牌以及顯示、語言和震動設定只儲存在你的裝置上。營運者無法查看，也不會備份或同步到其他裝置。

2. 下載謎題（GitHub Pages）

本應用程式從 GitHub, Inc. 營運的 GitHub Pages（boksday.github.io）下載謎題列表和謎題檔案。與任何網頁請求一樣，GitHub 會收到你的 IP 位址和請求時間等基本請求資訊。這些資訊由 GitHub 依照 GitHub 隱私權聲明處理，營運者不會收到。

3. 第三方為廣告蒐集的資訊

本應用程式免費提供，並顯示 Google LLC 的 Google AdMob 廣告：每個畫面底部都有橫幅廣告；心用完時，如果你選擇觀看，會顯示獎勵一顆心的獎勵廣告。AdMob 可能為投放和衡量廣告、防止作弊而蒐集和處理以下資訊。

蒐集方項目目的
Google LLC (AdMob)廣告識別碼（Android 廣告 ID；iOS 的 IDFA 僅在你允許追蹤時）、IP 位址、裝置、系統和應用程式資訊、廣告曝光和點擊等互動資訊顯示廣告和個人化廣告、衡量廣告成效、防止無效點擊

詳見Google 如何使用採用其服務的網站或應用程式所提供的資訊和 Google 隱私權政策。

4. 廣告同意與關閉個人化廣告

  • 在歐洲經濟區、英國等需要同意的地區，本應用程式會透過 Google 的同意工具（UMP）徵求你的廣告隱私權同意，你可以隨時在應用程式的設定 → 廣告隱私設定中更改（僅在需要同意的地區顯示）。
  • iOS：可在「App 追蹤透明度」視窗中選擇是否允許追蹤，之後可隨時在設定 → 隱私權與安全性 → 追蹤中更改。如不允許，只會顯示非個人化廣告。
  • Android：在設定 → Google → 廣告中刪除或重設廣告 ID。

5. 保存與刪除

裝置上的紀錄和設定會在刪除應用程式時一併刪除。營運者不另外保存任何資訊。第三方（Google、GitHub）蒐集的資訊依其各自的政策保存。

6. 兒童隱私

本應用程式並非主要以 13 歲以下（韓國為 14 歲以下）的兒童為對象，也不會刻意蒐集兒童的個人資訊。
