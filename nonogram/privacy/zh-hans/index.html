BySide 数织 隐私政策

生效日期：2026年10月13日

BySide 数织（以下简称“本应用”，iOS 和 Android）重视你的隐私。本政策说明本应用处理哪些信息以及如何处理。

1. 本应用收集的信息

本应用没有注册或登录，也不会把你的信息发送到运营者的服务器或数据库。运营者不会从本应用收到任何信息。

解开的图画、进行中的游戏、奖牌以及显示、语言和振动设置只保存在你的设备上。运营者无法查看，也不会备份或同步到其他设备。

2. 下载谜题（GitHub Pages）

本应用从 GitHub, Inc. 运营的 GitHub Pages（boksday.github.io）下载谜题列表和谜题文件。与任何网页请求一样，GitHub 会收到你的 IP 地址和请求时间等基本请求信息。这些信息由 GitHub 按照 GitHub 隐私声明处理，运营者不会收到。

3. Game Center（iOS）

仅当你在设备上登录 Game Center 时，本应用才会把收集的奖牌数（用于排行榜）和成就发送到 Apple Game Center。排行榜会显示你的 Game Center 昵称。这些信息由 Apple 按照 Apple 隐私政策处理。你可以在“设置”中关闭 Game Center。

4. 购买（移除广告）

移除广告的购买由 App Store 或 Google Play 处理。运营者不会收到银行卡号等支付信息，本应用只在设备上确认商店告知的购买状态。移除广告为一次性购买，不会自动续费。

5. 第三方为广告收集的信息

本应用免费提供，并显示 Google LLC 的 Google AdMob 广告：每个界面底部都有横幅广告；心用完时，如果你选择观看，会显示奖励一颗心的激励广告。AdMob 可能为投放和衡量广告、防止作弊而收集和处理以下信息。

收集方项目目的
Google LLC (AdMob)广告标识符（Android 广告 ID；iOS 的 IDFA 仅在你允许跟踪时）、IP 地址、设备、系统和应用信息、广告展示和点击等互动信息展示广告和个性化广告、衡量广告效果、防止无效点击

详见Google 如何使用来自使用其服务的网站或应用的信息和 Google 隐私权政策。

6. 广告同意与关闭个性化广告

  • 在欧洲经济区、英国等需要同意的地区，本应用会通过 Google 的同意工具（UMP）征求你的广告隐私同意，你可以随时在应用的设置 → 广告隐私设置中更改（仅在需要同意的地区显示）。
  • iOS：可在“App 跟踪透明度”弹窗中选择是否允许跟踪，之后可随时在设置 → 隐私与安全性 → 跟踪中更改。如不允许，只会显示非个性化广告。
  • Android：在设置 → Google → 广告中删除或重置广告 ID。

7. 保存与删除

设备上的记录和设置会在删除应用时一并删除。运营者不另外保存任何信息。第三方（Google、GitHub）收集的信息按其各自的政策保存。

8. 儿童隐私

本应用并非主要面向 13 岁以下（韩国为 14 岁以下）的儿童，也不会有意收集儿童的个人信息。
